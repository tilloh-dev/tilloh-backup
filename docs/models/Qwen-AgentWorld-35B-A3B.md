# Qwen-AgentWorld-35B-A3B
> Extracted verbatim from AGENTS.md on 2026-08-15. "Above/below" references may point
> to sibling files in this directory or back to AGENTS.md.

Qwen-AgentWorld-35B-A3B (Qwen, Apache-2.0, language world model): 35B-A3B MoE (arch `qwen35moe`, base Qwen3.5-35B-A3B, 40 layers, 256 experts + 8 routed/1 shared active) that simulates 7 agent environments (MCP/Search/Terminal/SWE/Android/Web/OS) via long CoT. Not a coding assistant — it predicts the *next environment state* given an action, so it is the counterpart to an agent, not one. Hybrid attention (10×(3× Gated-DeltaNet → MoE → 1× Gated-Attention → MoE)) means only ~10 of 40 layers carry a growing KV-cache, so long contexts are cheap on VRAM. `UD-IQ4_XS` (16961 MiB) is the smallest 4-bit build that keeps quality; the next steps up (`UD-Q4_K_S` 20.9 GB, `UD-Q4_K_M` 22.1 GB) would not leave room for a 262k KV cache. **Measured on hermine 2026-08-05** with four real loads at KV `q8_0`/`q8_0`, `fit = off`: the full native `ctx-size = 262144` holds at **21082–21104 MiB of 23028** (~1930 MiB free) with **6773–6944 t/s prompt** and **139.3–142.8 t/s generation**, no CPU offload. Unlike Ornith-1.0-35B there is **no cliff**: 196608 (2815 free) and 131072 (3683 free) measure 137.1 and 139.6 t/s, i.e. flat, so nothing is gained by shrinking. `fit = on` was tried too and behaves identically here (139.3 t/s, no offload), so `fit = off` is a no-op as measured — it is set anyway so that a future VRAM shortfall fails loudly instead of silently switching to the offloaded mode that cost Ornith-1.0-35B ~30 %. Shrinking ctx would also contradict the card, which advises **at least 128K** because the model uses extended context for multi-turn simulation. `cache-type-v` was `q4_0` and is now matched to K — that was the section's only real defect. Vendor sampling confirmed verbatim from the card: `temp 0.6`, `top-p 0.95`, `top-k 20`; thinking mode is on by default (`<think>…</think>`) → `jinja = true` + `reasoning-format = auto`, and the card's reasoning parser is `qwen3`. It also recommends ~32768 output tokens per query and ships domain-specific system prompts in the GitHub repo's `prompts/` — both are client-side, not preset keys.
