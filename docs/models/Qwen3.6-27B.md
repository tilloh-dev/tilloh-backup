# Qwen3.6-27B
> Extracted verbatim from AGENTS.md on 2026-08-15. "Above/below" references may point
> to sibling files in this directory or back to AGENTS.md.

Qwen3.6-27B (unsloth `-MTP-` build, `IQ4_XS`): the MTP speculator ships inside the GGUF, so `spec-type = draft-mtp` needs **no** `model-draft`. Presets differ per machine: **hermine** (RTX 4090, 23028 MiB, CUDA) `ctx-size = 131072`, KV `q8_0`/`q8_0`, `spec-draft-n-max = 3` — measured 2026-08-04 at 21877 MiB peak (~1.1 GiB free), 2516 t/s prompt / 97 t/s generation; **lieselotte** (7900 XTX, Vulkan) `device = Vulkan0`, `ctx-size = 262144`, KV `q8_0`/`q4_0`, `spec-draft-n-max = 4`. Sampling: the card gives two thinking-mode sets — `temp 1.0` for general tasks and `temp 0.6` for precise coding — both with `top-p 0.95`, `top-k 20`, `min-p 0.0`, `presence-penalty 0.0`; hermine's preset uses the 0.6 coding set, lieselotte still uses 1.0. hermine additionally chains a second, draft-model-free speculator: `spec-type = draft-mtp,ngram-mod` with `spec-ngram-mod-n-match/min/max = 24/48/64` (these three equal the build's defaults and are written out only to be explicit). ngram-mod is a 16 MiB host-RAM hash table (no VRAM) that hashes the last 24 tokens and chains up to 64 drafted tokens, discarding the draft entirely if the chain breaks before 48 — so it pays off on verbatim repeats (file rewrites, quoted diffs) and stays silent on novel text. Priority is **hardcoded in llama.cpp, not list order** (`common/speculative.cpp` `common_speculative_init`): all `ngram-*` implementations run before all `draft-*`, so MTP only drafts when ngram-mod returns nothing. Enabling it also raises the global draft budget to 64 via `common_speculative_n_max`, which enlarges the verification batch. Speed impact on hermine is **unmeasured** — the 97 t/s above predates it. `fit = off` is set deliberately although it is nearly a no-op here (`--fit` only adjusts arguments left unset, and this section sets `ctx-size`/`n-gpu-layers` itself); the real effect is that a VRAM shortfall now fails loudly instead of silently shrinking, which matters because the measured peak leaves only ~1.1 GiB free.
