# Ornith-1.0-9B
> Extracted verbatim from AGENTS.md on 2026-08-15. "Above/below" references may point
> to sibling files in this directory or back to AGENTS.md.

Ornith-1.0 (DeepReinforce/ornith-ai, MIT, agentic coding): post-trained on Gemma 4 and Qwen 3.5, so the 9B reports arch `qwen35` — which is why its sampling looks like Qwen's. It is not copied: the card recommends `temp 0.6`, `top-p 0.95`, `top-k 20` verbatim (and `temp 1.0` only to reproduce the published benchmarks), so the values already in both presets are vendor-correct. A reasoning model — the assistant turn opens with `<think>…</think>` by default, and the vendor's serving recipes add a reasoning parser plus a `qwen3_xml`/`qwen3_coder` tool-call parser, which `jinja = true` + `reasoning-format = auto` cover. Unlike Laguna the embedded template does **not** default thinking off, so no explicit `reasoning = on`. **9B measured on hermine 2026-08-05** by loading at the full native `ctx-size = 262144`, KV `q8_0`/`q8_0`: **14958–14977 MiB of 23028** (~8060 MiB free), **9247 t/s prompt** (7230-token prompt), 75.3 t/s generation on a short prompt and 73.7 t/s after the long one. No MTP drafter exists for it, so `llama-fit-params` is complete here rather than a lower bound — and its estimate (13783 MiB) came within ~1.2 GiB of the real load. The 8 GiB left idle cannot be turned into context — 262144 is already `n_ctx_train`. It could *almost* be turned into a better quant, and an earlier version of this paragraph got that wrong by mixing decimal GB with GiB: BF16 is 17.9 GB **decimal** = 17071 MiB, and 17071 + the measured 5872 MiB of KV/compute = 22943 of 23028, so it would nominally fit with 85 MiB to spare rather than "not fit". The reason to stay on Q8_0 is throughput, not capacity. Generation here is memory-bandwidth-bound: 75.3 t/s × 9.53 GB of weights ≈ 718 GB/s effective against the 4090's ~1008 GB/s spec, so doubling the weight bytes would land near **40 t/s**. That number is **computed from the measured one, not measured** — nobody has loaded a BF16 build of this model on this box. Two runs bracket what `ngram-mod` is worth on novel text — 75.30 t/s with it against 75.32 t/s without, i.e. nothing, exactly as the mechanism predicts. `cache-type-v` was `q4_0` (lieselotte's Vulkan floor) and is now matched to K on hermine.
